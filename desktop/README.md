# Billaura desktop (Windows)

Built automatically by `.github/workflows/desktop.yml`: GitHub → **Actions** → **Build Windows app** → **Run workflow**. When it finishes (about 3–5 minutes), open the run and download **Billaura-Windows** from *Artifacts*. Inside: `Billaura-1.0.0-x64.exe` (installer) and a portable `.exe`.

Pushing a tag such as `v1.0.0` also attaches the files to a GitHub Release.

Data on the PC is stored separately from the phone. Sign in with the same cloud account on both to sync.
