How to install

  1. Android: download the APK, open it, allow "Install unknown apps" if asked, tap Install.
  2. Windows: run Billaura-Setup.exe. If SmartScreen appears choose More info, then Run anyway.
  3. Any device: open in Chrome or Edge and choose Install app from the menu.

Questions

Is Billaura really free to start?

Yes. The Free plan has no time limit and is built for small shops. Pro plans lift the limits and unlock extras like the online store. Plans and prices are shown inside the app.

Do I need internet?

No. Billing works offline. Internet is only needed for sign-in, cloud backup, licence checks and updates.

How do updates work?

Browser and installed web app: automatic. Windows app: downloads the new version in the background and installs when you close it. Android: you get an in-app notice with a download button; tap it and install over the old version, your data is kept.

Is my data safe?

Data is stored on your device and, when you sign in, in your private cloud account protected by row-level security so only your shop can read it.

Will Android warn me when installing the APK?

Yes, because it is installed outside the Play Store. Allow 'Install unknown apps' for your browser once, then it installs normally.

Windows says 'unknown publisher'.

The app is not yet code-signed. Choose 'More info' then 'Run anyway'. This is normal for new independent software.
